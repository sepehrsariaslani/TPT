# TPT — لندینگ پیج کارخانه تزریق پلاستیک

لندینگ تک‌صفحه‌ای فارسی (RTL) با صحنه‌ی سه‌بعدی اسکرول‌محور:
گرانول‌های پلاستیکی در فضا می‌بارند، به میدان مارپیچ می‌پیوندند، روی سطح مدل سه‌بعدی محصول می‌نشینند،
محصول واقعی شکل می‌گیرد و با ادامه‌ی اسکرول دوباره به گرانول تجزیه می‌شود.

## اجرا
بدون مرحله بیلد — همه‌ی کتابخانه‌ها لوکال (پوشه `vendor`) هستند:

```bash
python3 serve.py      # http://localhost:3000  (بدون کش)
```

## استک
| لایه | ابزار |
|---|---|
| رابط کاربری | HTML + CSS (RTL، بدون فریم‌ورک) |
| صحنه سه‌بعدی | **Three.js r185** (`vendor/three`) |
| کنترل اسکرول | **GSAP + ScrollTrigger** (scrub) |
| پس‌پردازش | UnrealBloom + OutputPass |
| ذرات | `InstancedMesh` + `MeshSurfaceSampler` |
| فالبک | `js/scene-2d.js` (Canvas 2D) برای مرورگر بدون WebGL/importmap |

## ساختار
- `index.html` — کل صفحه (هیرو، صحنه، خدمات، توانمندی‌ها، صنایع، گالری، مراحل، سوالات، تماس)
- `js/three-scene.js` — صحنه Three.js و تایم‌لاین اسکرول
- `js/cap-model.js` — مدل پروسیجرال درب (بدنه Lathe + شیارهای کناری + شیارهای هم‌مرکز)
- `js/models.js` — پنج مدل محصول (درب پیچی، فلیپ‌تاپ، درب سطل، ظرف جداره‌نازک، اتصال آبیاری)
- `js/carousel.js` — کاروسل سه‌بعدی محصولات: چرخش با درگ/لمس/کیبورد، تعویض محصول، تغییر رنگ متریال
- `js/scene-2d.js` — نسخه فالبک دوبعدی
- `js/main.js` — منو، انیمیشن ورود بخش‌ها، شمارنده‌ها، فرم
- `css/style.css` — استایل و ریسپانسیو
- `vendor/` — Three.js، GSAP، ScrollTrigger و addonهای لازم (آفلاین)
- `assets/` — تصاویر گالری و رندر مرجع محصول

```
0.30  گردابه فشرده می‌شود
0.42  جذب ذرات به نقاط سطح مدل
0.62  ماده محصول ظاهر می‌شود، ذرات محو می‌شوند
0.78  محصول کامل، چرخش آرام و دالی دوربین

```
اسکرول کاملاً scrub است: توقف = توقف انیمیشن، اسکرول به بالا = اجرای معکوس.

## جایگزینی با مدل واقعی (Blender / CAD) — آماده است
مسیر GLB از قبل در کد پیاده شده. کافی است فایل مدل واقعی را اینجا بگذارید:

```
assets/product.glb
```

هنگام بالا آمدن صفحه، `js/three-scene.js` وجود این فایل را چک می‌کند و اگر بود:
1. با `GLTFLoader` لود می‌شود؛
2. به‌صورت خودکار مرکز و مقیاس می‌شود (بزرگ‌ترین بعد = ۲ واحد، کف روی y=0)؛
3. متریال آبی محصول روی همه‌ی مش‌ها اعمال می‌شود؛
4. بزرگ‌ترین مش به `MeshSurfaceSampler` داده می‌شود و **مقصد همه‌ی گرانول‌ها دوباره روی سطح مدل واقعی محاسبه می‌شود**؛
5. مدل پروسیجرال از صحنه حذف می‌شود.

اگر فایل نبود، همان مدل پروسیجرال کار می‌کند؛ هیچ خطایی رخ نمی‌دهد.

**خروجی گرفتن از Blender:** File → Export → glTF 2.0 (.glb)، با فشرده‌سازی Draco و
یکی‌کردن مش‌ها (Join) برای بهترین نتیجه در نمونه‌برداری ذرات.
از CAD (STEP/IGES) هم می‌توانید به STL/OBJ خروجی بگیرید، در Blender وارد کنید،
مش را Decimate کنید (زیر ۱۰۰ هزار مثلث) و GLB بگیرید.

## تنظیمات سریع
- طول صحنه: `height` روی `.scene` در CSS
- تعداد گرانول‌ها: ثابت `COUNT` در `js/three-scene.js`
- شدت درخشش: `bloom.strength`
- رنگ محصول: `capMat.color`
- متن مراحل: بلوک‌های `.hud__step` در `index.html`

فرم تماس فعلاً فقط سمت کلاینت است و باید به سرویس ایمیل/CRM وصل شود.
