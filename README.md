# TPT — لندینگ پیج کارخانه تزریق پلاستیک

لندینگ تک‌صفحه‌ای فارسی (RTL) با انیمیشن اسکرول: گرانول‌های پلیمر با اسکرول کردن وارد قیف می‌شوند،
ذوب می‌شوند، به داخل قالب تزریق شده و در نهایت به قطعه نهایی تبدیل می‌شوند.

## اجرا
هیچ ابزار بیلدی لازم نیست — فقط یک سرور استاتیک:

```bash
python3 -m http.server 3000
# http://localhost:3000
```

## ساختار
- `index.html` — کل محتوای صفحه (هیرو، صحنه اسکرول، خدمات، توانمندی‌ها، صنایع، گالری، مراحل سفارش، سوالات، فرم تماس)
- `css/style.css` — استایل و ریسپانسیو
- `js/scene.js` — موتور انیمیشن canvas (ذرات گرانول → قطعه) که به اسکرول متصل است
- `js/main.js` — منو، انیمیشن ورود بخش‌ها، شمارنده اعداد، اعتبارسنجی فرم
- `assets/` — تصاویر گالری

## نکات قابل تنظیم
- طول انیمیشن: مقدار `height: 600svh` روی `.scene` در CSS
- تعداد ذرات: تابع `layout()` در `js/scene.js`
- شکل قطعه نهایی: توابع `productPath` و `rimPath` در `js/scene.js`
- متن مراحل: بلوک‌های `.hud__step` در `index.html`
- فرم تماس فعلاً فقط سمت کلاینت است؛ برای دریافت واقعی باید به یک اندپوینت یا سرویس ایمیل وصل شود.
