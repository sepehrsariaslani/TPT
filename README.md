# TPT — Granule to Product Scroll Experience

نسخه‌ی این برنچ یک تجربه‌ی سه‌بعدی واقعی و وابسته به اسکرول است؛ ویدئو نیست. گرانول‌های پلاستیکی از بالا وارد می‌شوند، در چند رشته و گردابه‌ی مارپیچ دور مرکز می‌چرخند، آرام روی فرم محصول می‌نشینند و درب پلاستیکی شکل می‌گیرد. با ادامه‌ی اسکرول، مسیر برعکس می‌شود و محصول دوباره به گرانول تجزیه می‌شود.

## Stack

- React 19
- Vite
- Three.js
- React Three Fiber
- Drei
- React Three Postprocessing
- WebGL / InstancedMesh
- Bloom + Vignette post-processing

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده توسط Vite را باز کنید.

برای تست بیلد production:

```bash
npm run build
npm run preview
```

## جزئیات صحنه

### Plastic granules

گرانول‌ها با `InstancedMesh` رندر می‌شوند تا هزاران قطعه با draw-call کم نمایش داده شوند. تعداد ذرات بر اساس عرض نمایشگر کاهش پیدا می‌کند تا موبایل فشار GPU کمتری داشته باشد.

### Flow paths

برای هر گرانول چند مقصد از قبل ساخته می‌شود:

```text
vertical stream → conical vortex → cap surface → release vortex → downward exit
```

بین این نقاط interpolation نرم انجام می‌شود و روی مسیرها انحنای اضافه اعمال می‌شود تا حرکت شبیه خط مستقیم و مصنوعی نباشد.

### Product

در حال حاضر محصول یک درب پیچی پروسیجرال است که داخل Three.js ساخته می‌شود و شامل این بخش‌هاست:

- سطح بالایی
- دیواره‌ی اصلی
- رینگ بالا و پایین
- رینگ داخلی
- 112 شیار عمودی پیرامونی
- متریال فیزیکی براق آبی

این انتخاب عمداً انجام شده تا پروژه بدون هیچ فایل سه‌بعدی خارجی هم قابل اجرا باشد.

## مدل واقعی محصول TPT

برای نسخه‌ی نهایی باید فایل سه‌بعدی محصول واقعی جای مدل پروسیجرال قرار بگیرد. فرمت پیشنهادی `GLB` است. بهترین مسیر این است که فایل CAD یا STEP محصول به Blender منتقل، سبک‌سازی و سپس به GLB تبدیل شود.

وقتی مدل واقعی اضافه شود، مرحله‌ی بعدی این است که نقاط مقصد گرانول‌ها به جای فرمول درب فعلی از سطح همان Mesh نمونه‌برداری شوند؛ در نتیجه گرانول‌ها دقیقاً فرم محصول واقعی را می‌سازند.

پیشنهاد برای مدل وب:

- حداکثر حدود 50k–100k triangles برای هر محصول اصلی
- تکسچرها WebP/AVIF در صورت نیاز
- GLB فشرده
- محور و scale تمیز قبل از export

## Performance

- DPR روی دسکتاپ محدود شده است.
- تعداد گرانول در موبایل کاهش می‌یابد.
- همه‌ی گرانول‌ها یک geometry مشترک دارند.
- particle movement با یک `InstancedMesh` انجام می‌شود.
- post-processing فقط Bloom و Vignette است.
- صحنه‌ی سه‌بعدی sticky است و خود صفحه فقط scroll progress را به WebGL منتقل می‌کند.
